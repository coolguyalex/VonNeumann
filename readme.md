# Probe Colony

A 2D game about a lone autonomous machine that wakes up on an alien planet and has to build a colony from nothing.

Built in [Godot](https://godotengine.org/). Early prototype, work in progress.

## The idea

Terraria's tactile digging, Dwarf Fortress's emergent colony systems, and Factorio's automation, with survival reframed as machine maintenance. There's no hunger: you manage charge, and later lubricant and part wear.

- **Start meager.** A bare machine with slow manual mining and no crafting. You feel the friction first.
- **Build up in tiers.** Fabrication and smelting modules unlock recipes and refined materials.
- **Build rovers.** Assemble rovers from a chassis, mobility, extraction, and sensor parts, then put them to work.
- **Program them.** A simple visual block language, in the spirit of *7 Billion Humans*, where the sensors you attach decide which conditions you can even ask about.
- **Belts or rovers.** Both stay useful all game. Paving a route is cheap and fast but fixed. A rover is flexible but costs upkeep.

## Status

Tier 0 prototype: a single hand-controlled machine, mining, and a charge stat.

## Running it

1. Install Godot 4.
2. Clone this repo.
3. Open Godot's Project Manager, choose **Import**, and select `probe_colony/project.godot`.
4. Press **F5** to run.
